## 📖 Overview

**Noma** is an immersive portfolio interface designed and developed by **Javlon Ilyasov**. Built to break away from traditional flat layouts, Noma merges high-contrast neon palettes with interactive physics, glitch typography, and animated matrix elements to create a distinctive cyberpunk atmosphere.

### ✨ Key Features

- **🎮 Cyberpunk Aesthetic:** Custom radial lighting, neon borders, and dark sci-fi gradients.
- **✨ Physics-Driven Particles:** Mouse-following cursor particle trails and floating background spheres.
- **💻 Matrix Digital Rain:** CSS/Canvas-powered digital rain stream on the hero section.
- **🎴 3D Tilt & Parallax Cards:** Dynamic card perspective rendering responding to cursor coordinates.
- **⚡ Glitch & Typing Typography:** Custom typewriter loops and glitch animations for heading typography.
- **📱 Fully Responsive:** Adaptive layout tailored for seamless viewing across smartphones, tablets, and high-DPI desktop screens.

## 🚀 Quick Start

### Prerequisites

- [Node.js](https://nodejs.org/) (`v18` or later)
- Package manager (`npm`, `pnpm`, or `yarn`)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Ilyasov09/noma.git
   cd noma
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` to explore the project.

4. **Production Build:**
   ```bash
   npm run build
   ```
